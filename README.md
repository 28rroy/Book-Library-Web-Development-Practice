# Book Library — Web Development Practice

This project was inspired by web development tutorials and built for personal practice to strengthen my skills with Node.js, Express, EJS, and MongoDB.
The application includes book and author records, forms for adding books, search filters, and book cover image storage.

## Skills Practiced

- Building Express routes and handling form submissions
- Rendering dynamic pages with EJS templates
- Working with MongoDB through Mongoose
- Filtering books by title and publication date
- Processing and storing book cover images
- Configuring environment variables

## Tech Stack

JavaScript · Node.js · Express · EJS · MongoDB · Mongoose

## Project Structure

- `server.js` — Application setup and database connection
- `routes/` — Request handlers for books, authors, and the home page
- `models/` — Database models
- `views/` — EJS page templates
- `public/` — Client-side JavaScript

## Status

This repository documents my learning and experimentation. It is a work in progress, rather than a production-ready application.
